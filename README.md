# Codveda Data Science & Analytics Internship Tasks

## 📌 Project Overview
This repository contains a series of data analysis and machine learning tasks completed during my internship at Codveda. The project is structured into three progressive levels, demonstrating a journey from fundamental data exploration to advanced predictive modeling and sentiment analysis.

## 🚀 Key Projects & Insights
1. Iris Species Classification (Level 1: Basic)
Objective: Exploratory Data Analysis (EDA) and classification of the classic Iris dataset.
Key Insight: Successfully identified distinct clusters and patterns using Python-based visualizations to differentiate species based on petal and sepal dimensions.

2. House Price Prediction (Level 2: Intermediate)
Objective: Building a predictive model to estimate housing prices based on various features.
Technical Focus: Feature engineering, handling missing values, and regression modeling.

3. Sentiment Analysis (Level 3: Advanced)
Objective: Analyzing textual data to determine sentiment polarity.
Visual Impact: Created a high-fidelity Power BI Dashboard to visualize sentiment trends and distribution across the dataset.

## 🛠️ Tech Stack
- Languages: Python (Pandas, NumPy, Scikit-Learn)
- Analysis: Jupyter Notebooks (.ipynb)
- Visualization: Power BI (.pbit), Matplotlib/Seaborn
- Design: Professional, minimalist dashboard aesthetics.

## Repository Structure
1) iris.csv: Raw data for basic classification.
3) Sentiment dataset.csv: Text data used for sentiment modeling.
4) house Prediction Data Set.csv: Dataset for regression analysis.
Level 1-3.ipynb: Detailed Python notebooks for each internship task.
Sentiment.pbit: Interactive Power BI template.
